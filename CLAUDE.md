# Instrucciones para el asistente

Antes de cualquier tarea de informes, capturas, código de asignaturas o entregas, lee completo
[`docs/GUIA-INFORMES.md`](docs/GUIA-INFORMES.md): contiene las reglas de redacción (voz impersonal),
el formato de los informes, cómo describir el uso de IA, cómo tomar capturas, cómo hacer commits y
qué no subir al repositorio. Responde siempre en español.
